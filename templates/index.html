About Project

Architecture, workflow pipeline, and methodology

Project Abstract

This project presents an automated, computer vision-assisted approach to estimate water pH using standard chemical pH test strips. By capturing strip photographs, OpenCV processes the image to isolate the indicator pad, extract color features in the HSV (Hue, Saturation, Value) color space, and feed them into a pre-trained Random Forest Regression machine learning model.

The predicted pH value is subsequently classified into Acidic (pH < 6.5), Safe / Neutral (6.5 ≤ pH ≤ 8.5), or Alkaline (pH > 8.5) to evaluate water potability.

Pipeline Workflow

1
Image Upload & Validation User uploads pH strip image (JPG/PNG), validated for file format and dimensions.
2
OpenCV Preprocessing Image resizing, Gaussian blur filtering (5x5 kernel), and Canny edge detection.
3
ROI Detection & Fallback Contour bounding-box extraction with intelligent central-region fallback to prevent demo failures.
4
HSV Feature Extraction Conversion to HSV color space and computation of Mean Hue, Mean Saturation, and Mean Value.
5
Random Forest Regressor Features passed to water_quality_model.pkl to predict numerical pH and calculate model confidence.
6
SQLite Persistence & Dashboard Results stored locally in SQLite analyses table and rendered with dynamic Chart.js analytics.

Project Notes & Limitations

Academic Demonstration Disclaimer: This application is built as a college mini-project demonstration. It utilizes a local SQLite database and a machine-learning regression model trained on calibrated pH colorimetric standards. It does not employ cloud databases (such as Firebase), IoT hardware probes, or laboratory validation. Camera lighting, shadows, and camera white-balance variations can affect color extraction.
